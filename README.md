# DocuHub Releases

Downloads und Updates für **DAGIO DocuHub**, ein DITA-Dokumentenmanagement für den Desktop (macOS und Windows).

- Die aktuelle Version steht unter [Releases](../../releases/latest).
- DocuHub prüft auf Wunsch selbst auf neue Versionen (Hilfe → Nach Updates suchen). Updates sind signiert; die App installiert nur Dateien mit gültiger Signatur.
- Der Quellcode ist nicht öffentlich.

Installation unter macOS: DMG öffnen, DocuHub in „Programme“ ziehen; beim ersten Start Rechtsklick → „Öffnen“.
Installation unter Windows: `.msi` ausführen; bei der SmartScreen-Warnung „Weitere Informationen“ → „Trotzdem ausführen“.
